# FitTrack — Trabalho 3: Modelagem


## Sobre este repositório

Este repositório contém o Trabalho 3 da disciplina Engenharia de Software, desenvolvido sobre o sistema **FitTrack**, plataforma de rastreamento de atividades físicas.

A filosofia adotada é profundidade sobre largura: em vez de modelar superficialmente todo o sistema, foram selecionadas três fatias verticais representativas e modeladas em profundidade.
